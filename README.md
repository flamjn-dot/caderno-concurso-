# Caderno de Concurso

Caderno digital simples para organizar matérias e anotações.

- login próprio por e-mail e senha;
- sincronização entre celular e computador;
- matérias e galeria de notas;
- editor com formatação e título opcional;
- favoritas, pesquisa e lixeira;
- exportação e importação de backup.

O aplicativo é uma página estática hospedada gratuitamente no GitHub Pages.
Os dados são protegidos por autenticação e políticas de acesso no Supabase.
